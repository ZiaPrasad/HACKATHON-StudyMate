# StudyMate

AI-powered academic assistant that helps students manage their academic life through natural-language and voice interactions.

> **You don't maintain StudyMate. StudyMate maintains your academic life.**

## Tech Stack

- React
- Vite
- Tailwind CSS
- Supabase
  - Authentication
  - PostgreSQL Database
  - Row Level Security
  - Edge Functions
- Groq API
- Web Speech API
- Browser Notifications

## Features

- AI Academic Assistant
- Natural-language academic commands
- Voice interaction
- Subjects
- Timetable
- Assignments
- Exams
- Attendance tracking
- Notes
- Study tasks
- Reminders and notifications
- AI-powered task prioritization
- Attendance analysis
- Deadline and workload analysis
- Personalized study planning
- Proactive academic alerts
